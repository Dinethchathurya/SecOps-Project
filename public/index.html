Interactive Security Flaw Demonstrations

Target: Gitleaks CWE-798

1. Secrets & Credentials Leak

High-entropy AWS keys, private RSA certificates, and mock production database connection URIs committed into repository.

AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
DATABASE_URL=postgres://secops_admin:SuperSecret...
Target: SonarCloud CWE-89

2. SQL Injection (SAST)

Raw user input concatenated directly into SQLite SQL query string without prepared statements.

Target: SonarCloud CWE-79

3. Reflected Cross-Site Scripting

Express route renders query parameter directly into raw HTML template without HTML encoding or CSP headers.

Target: SonarCloud CWE-327 / CWE-328

4. Insecure MD5 & SHA-1 Hashing

Passwords stored using broken, un-salted MD5 hash function vulnerable to instant rainbow table inversion.

Target: Snyk SCA CWE-1321

5. Outdated Dependencies (Prototype Pollution)

Uses lodash@4.17.15 (CVE-2019-10744), axios@0.21.1, and jsonwebtoken@8.5.1.

Target: Trivy CWE-250

6. Outdated Docker Base & Root Execution

Dockerfile runs on vulnerable node:14-alpine containing OS CVEs, runs as USER root, and embeds netcat, curl, and telnet.

FROM node:14.21.3-alpine3.17 # Unpatched OS CVEs
USER root # Privilege escalation vulnerability
RUN apk add curl netcat-openbsd telnet # Unneeded tools

DevSecOps Detection & Coverage Matrix

Vulnerability Location Detecting Scanner Why Other Scanners Ignored It Remediation Step
AWS Keys & Private RSA Certs .env.example, src/config/ Gitleaks SAST, SCA, and Trivy do not search git history or calculate token Shannon entropy. Revoke exposed keys; inject secrets at runtime via Vault / AWS Secrets Manager.
SQL Injection src/routes/users.js SonarCloud Gitleaks lacks AST taint tracking; SCA only checks packages; Trivy checks container layers. Adopt parameterized queries (prepared statements) or an ORM with parameter binding.
Reflected XSS src/routes/profile.js SonarCloud String concatenation into HTTP responses is custom code logic, invisible to SCA & Trivy. Perform context-aware HTML entity encoding or enforce a strict Content-Security-Policy.
Broken Cryptography (MD5) src/routes/auth.js SonarCloud crypto is a built-in module (not a third-party CVE for SCA); Gitleaks ignores functions. Migrate to Argon2id, bcrypt, or PBKDF2-HMAC-SHA512 with per-user cryptographic salts.
Prototype Pollution & CVEs package.json (lodash, jsonwebtoken) Snyk Custom code SAST does not correlate dependency version tags against NVD/CVE databases. Upgrade to patched library releases (e.g., lodash >= 4.17.21).
Outdated OS Image & Root Execution Dockerfile Trivy SAST and SCA analyze application code/manifests; they do not inspect base OS libraries. Use minimal modern base (node:20-alpine), set USER node, remove netcat/curl.
